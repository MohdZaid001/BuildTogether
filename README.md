# BuildTogether — Hackathon Team Matcher

A beginner-friendly frontend project made with HTML, CSS and vanilla JavaScript.

## Features
- Browse participant cards and filter by skill.
- Search people by name or skill.
- Join an open team and update its vacancy count.
- Post a new team opening.
- Submit a project pitch with GitHub, demo and video links.
- Choose one of the three sponsor tracks.
- View and remove submitted projects.
- Save teams and submissions in browser LocalStorage.
- Responsive layout for desktop and mobile.

## Run locally
1. Download and extract the project.
2. Open `index.html` in a browser.
3. No installation or backend is required.

For a smoother development experience, open the folder in VS Code and use the Live Server extension.

## Important note
This is a frontend demonstration. LocalStorage saves data only in the current browser on the current device. It does not sync data between different users or devices. The sample people and teams are demo data.

## Deploy
You can upload these files to a GitHub repository and enable GitHub Pages from the repository's Settings → Pages section.

## Files
- `index.html` — page structure
- `style.css` — design and responsive layout
- `script.js` — filters, team actions, forms and LocalStorage
