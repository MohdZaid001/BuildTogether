# BuildTogether — Hackathon Team Matcher

A simple frontend demo for finding teammates, viewing open team positions and submitting a hackathon project pitch.

## Features
- Search participants by name or skill and filter by skill.
- View team openings and join action.
- Post a team opening with the number of current members and available positions.
- Submit a project title and GitHub link, demo and video links.
- View and remove project submissions.
- Save demo data in browser LocalStorage.
- Responsive layout for desktop, tablet and mobile screens.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.


## Files
- `index.html` — page structure and forms
- `style.css` — styling and responsive breakpoints
- `script.js` — search, filters, demo actions and LocalStorage
